## 🆕 v7.7: GIVG 2D+Time 生命周期矩阵 — "卡脖子 ≠ 值得现在买"

v7.6的GIVG 2D给了当前的IG/VG快照，但没有**随时间变化的轨迹**。
Ajinomoto ABF是最好的例子——2019年IG=0.9(没人知道味精公司做芯片材料)→2026年IG=0.15(每篇研报都提ABF)。
**同样是好公司，同样的卡脖子故事，但生命阶段完全不同。**

```
🟢发现期 → 🟡共识期 → 🔴耗竭期 → 📋Watchlist → 🔄再发现
 IG≥0.7    IG 0.3-0.7   IG<0.3      监控回归条件    IG≥0.5+VG≥0.6
 VG≥0.7    VG 0.35-0.7  VG<0.35     IG+VG+催化剂    黄金再进入
```

### 🔴 利好出尽6条信号

≥3→自动降级审查→找替代标的→转入Watchlist:

```
⚠️ 信号1: 股价12月翻倍+IG<0.2 → 利好已price in
⚠️ 信号2: 主流媒体全线覆盖卡脖子故事 → 信息真空=0
⚠️ 信号3: 券商一致买入≥80% → 反向指标
⚠️ 信号4: PE处于5年最高1/3分位 → 已贵

⚠️ 信号6: 业绩会卡脖子提及频率↓ → 叙事耗竭
```
