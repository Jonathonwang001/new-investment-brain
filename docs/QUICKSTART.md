# Quick Start — Investment Brain New v3.1 (三种时刻框架)

## 快速使用

### 1. 完整分析（日常使用）

```
请用 new-investment-brain 分析 {TICKER}
```

Agent 将自动执行：
1. 三种时刻判定（AJI/RPI/GATE分类）
2. Chokepoint四维扫描
3. 六大脑并行分析
4. Alpha Score + Alpha Phase
5. 分层推荐评级
6. 仓位建议
7. 输出完整报告

### 2. 快速评估（时间敏感场景）

```
请用 new-investment-brain 快速评估 {TICKER}
```

输出简版：时刻类型 | Chokepoint强度 | 财务分 | Alpha Score | Alpha Phase | 推荐评级 | 仓位建议

### 3. 三种时刻判定（🆕 v3.1核心功能）

```
请用 new-investment-brain 判定 {TICKER} 属于哪种时刻（AJI/RPI/GATE）
```

输出：时刻类型 + 时刻评分(0-100) + Serenity历史类比 + AI产业链定位 + Alpha Phase

### 4. 行业价值链分析

```
请用 new-investment-brain 分析 {行业} 产业链，找出三种时刻节点
```

### 5. Speed Breaker评估

```
{TICKER} 刚出了负面新闻 {事件}，请评估是否为Speed Breaker买入机会
```

## 核心原则（v3.1强化版）

1. **三种时刻判定前置**：任何标的先判断"是AJI/RPI/GATE时刻吗？"再进入财务分析
2. **AJI/GATE时刻可弥补财务分数**（RPI弥补力度较弱）
3. **Alpha Score≥60可突破财务闸门**（Serenity规则）
4. **技术面BEARISH + 财务差 = 无条件回避**
5. **3个🔴法医红旗 = 无条件回避**
6. **Stage 4 = 绝不买入**
7. **组合中时刻标的≥30%配置**（味之素+树莓派+关隘）
8. **每个信号必须有Proof-of-Work验证**
